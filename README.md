# Расписание КГМУ — копия сайта

Статичная копия сервиса расписания Казанского ГМУ (`calendar.kazangmu.org`), сделанная на
случай отключения оригинала (разработчик предупредил, что система перестанет работать
1 ноября 2026).

**Адрес:** https://regasukaa.github.io/kgmu-schedule/

## Как это работает

На странице два поля, как в оригинале: **группа** (список с поиском по номеру, можно
вписать вручную) и **даты** (по умолчанию — текущая учебная неделя), кнопка **Поиск**.
Результат — карточки занятий по датам: время, тип (лекция/практика/цикл), подгруппа,
аудитория, дисциплина, преподаватель.

Направление и курс отдельно выбирать не нужно: они вычисляются по номеру группы из базы.

Ссылку можно шарить: `?g=1206&from=2026-10-26&to=2026-11-01`.

## Источники данных

* `https://kazangmu.ru/obuchenie/studentam/raspisanie-zanyatij` — таблица ссылок на все
  направления и курсы;
* `https://calendar.kazangmu.org/api/schedule/front` — JSON расписаний (без капчи);
* Nextcloud КГМУ (`cloud.kazangmu.ru`) — Excel/PDF официальных расписаний.

## Структура

```
tools/scrape.py        # скачать каталог + JSON + Excel/PDF
tools/parse_xlsx.py    # недельные Excel-сетки -> JSON
tools/parse_cycles.py  # «РАСПИСАНИЕ ЦИКЛОВЫХ ЗАНЯТИЙ» (4-6 курс, даты)
tools/parse_weeks.py   # подробные недельные файлы отдельных групп
tools/render_pdfs.py   # PDF-сканы -> WebP
tools/build_base.py    # site/data/index.json + site/data/g/<группа>.json
tools/selftest.js      # автопроверка интерфейса в headless Edge
tools/cdp.py           # мини-клиент CDP (разведка сайта)
```

Порядок обновления:

```bash
py tools/scrape.py
py tools/parse_xlsx.py
py tools/parse_cycles.py
py tools/parse_weeks.py
py tools/render_pdfs.py
py tools/build_base.py
git add -A && git commit -m "обновление" && git push
git subtree push --prefix site origin gh-pages
```

## Покрытие

* 178 групп: 11 направлений очной формы (лечебное дело, педиатрия, стоматология,
  МПД, фармация, мед-биохимия, мед-биофизика, психология, сестринское дело,
  социальная работа, общественное здравоохранение);
* 4–6 курс — цикловые занятия с реальными датами из официального Excel;
* заочные и магистерские направления — сканы официальных документов (кнопка в подвале).

## Ограничения

1. Даты в базе получаются разворачиванием недельной сетки Excel на календарь
   (сетка — официальный документ на семестр, без привязки к числам).
2. В Excel ячейки объединены по колонкам групп, поэтому у группы могут появиться
   занятия соседней группы/подгруппы — сайт КГМУ раздаёт их точнее, но его API
   закрыт капчей (SmartCaptcha, ползунок).
3. Для групп 1103, 1203, 1303 есть только подробные недельные файлы (темы занятий),
   они показываются с пометкой «N-я неделя».
