# Статус проекта

Обновлено: 29.10.2026

## Сделано

* Каталог всех направлений и курсов спарсен с официальной страницы
  `kazangmu.ru/obuchenie/studentam/raspisanie-zanyatij` (62 позиции).
* Скачаны все источники: 30 JSON с `calendar.kazangmu.org/api/schedule/front`
  и 32 файла с Nextcloud КГМУ (`cloud.kazangmu.ru`).
* Разобраны недельные Excel-сетки (20 файлов), цикловые расписания (4 файла),
  PDF-сканы переведены в WebP (11 файлов, 27 страниц).
* Собран `site/data/schedule.json`: 15 направлений, 59 курсов, 4 505 занятий,
  198+195+40+130 циклов, 27 страниц сканов.
* Интерфейс: выбор направления → курса → группы, виды «Сетка» (как официальный
  документ) и «Дни» (карточки), поиск, тёмная тема, ссылка на конкретную группу.
* Опубликовано на GitHub Pages: https://regasukaa.github.io/kgmu-schedule/

## Проверено

* headless Edge: 0 наложений ячеек, 0 обрезанного текста, нет горизонтального
  переполнения страницы, нет JS-ошибок;
* мобильная ширина 390 px: сетка показывает только выбранную группу, ширина
  сетки = ширине контейнера (нет горизонтальной прокрутки);
* живой сайт на GitHub Pages отдаёт страницу, JSON и сканы (200).

## Что осталось

1. **Подробные недели для групп 1103 / 1203 / 1303.** В исходниках это отдельные
   Excel-файлы с 11 листами «N неделя» и темами занятий. Пока не подключены:
   нужен третий вид «Недели» и разбор листов.
2. **Сканы заочных/магистерских расписаний не распознаны в текст** — это
   картинки без текстового слоя (PDF-сканы). Сейчас показываются как страницы
   документа. Для текстового вида нужен OCR (tesseract + rus или ручная сверка).
3. **Автообновление.** Сейчас данные обновляются вручную (`tools/scrape.py` →
   `parse_xlsx.py` → `build_data.py` → `git push`). Можно повесить cron
   1–2 раза в сутки, чтобы ловить изменения.
4. **Проверка на реальном телефоне** — стоит открыть ссылку с iPhone/Android и
   посмотреть, как читается сетка.

## Как обновить

```bash
py tools/scrape.py        # каталог + JSON + Excel/PDF с сайтов КГМУ
py tools/parse_xlsx.py    # недельные сетки -> data/parsed
py tools/parse_cycles.py  # циклы -> data/parsed_cycles
py tools/render_pdfs.py   # PDF-сканы -> site/scans
py tools/build_data.py    # итог: site/data/schedule.json
git add -A && git commit -m "обновление расписаний" && git push
git subtree push --prefix site origin gh-pages
```

## Известные особенности источника

* В файле `pediatriya__cikly-*.xlsx` и `stomatologiya__cikly-*.xlsx` в шапке
  указано «31.05.01 Лечебное дело» — это ошибка самих файлов; направление
  определяется по имени файла (см. словарь `BASE` в `tools/build_data.py`).
* Ячейки Excel объединены по вертикали на пару, поэтому занятия склеиваются в
  пары 08:00–09:35 и т.п.; иногда объединение захватывает 4 строки — такие блоки
  показываются как одно длинное занятие.
* Внутри одной группы на одно время могут стоять занятия разных подгрупп — они
  выводятся в одной ячейке через разделитель.
